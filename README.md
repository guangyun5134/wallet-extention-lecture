# 浏览器钱包扩展开发教程

以浏览器插件为入口的钱包开发学习项目，包含环境搭建、扩展 API 示例和钱包开发讲解。

## 项目特点

- 使用 Plasmo 快速搭建 React 与 TypeScript 浏览器扩展。
- 通过分章节示例介绍 Popup 页面、存储、消息通信和扩展基础 API。
- 展示页面、Content Script 与 Background 之间的协作方式。
- 包含钱包创建、导入和交互流程的学习资料，便于逐步理解扩展架构。

## 目录

- `01.env/`：开发环境搭建及基础扩展示例。
- `02.baseAPI/`：浏览器扩展 API 与通信示例。
- `03.wallet/`：钱包开发讲解。

技术栈：Plasmo、React、TypeScript、Tailwind CSS。具体运行步骤见各章节 README。
