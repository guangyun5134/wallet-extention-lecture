# 钱包插件环境搭建

## 主要内容

项目初始化 - 如何快速创建项目并启动开发
Tailwind CSS 配置 - 如何在 Plasmo 中使用 Tailwind

```bash
# 1. 安装pnpm包管理器
npm i -g pnpm
# 使用 pnpm 创建项目
pnpm create plasmo --with-tailwindcss
```

## 核心 API 介绍：

Storage API - 数据存储、Hook 使用、存储区域选择、监听变化
Messaging API - 组件间消息通信
Tabs API - 标签页操作
openPopup - 多种打开弹窗的方式
